# 归青 · 一物一纹｜作品集可交互网页

本目录是 `06_交付\C01_归青_龙泉青瓷作品集.pdf`（24P / A4 横版 297×210mm / 15.02MB）的**可交互网页版**。

## 怎么打开

直接双击 `index.html`，浏览器即可打开；不需要服务器、不需要联网。

```
08_网站/
├── index.html      ← 打开这个
└── pages/          ← p01.jpg … p24.jpg（PDF 逐页渲染的页面图像）+ 24 张缩略图 + p01@2x.jpg（封面高清版）
```

- `index.html` 是**单文件自包含**的：24 页页面图像以 base64 内嵌在文件尾部（4.19 MB）。
  即使只把 `index.html` 单独拷走，也能完整打开、翻页、检索。
- 同目录 `pages/` 里的 24 张 JPEG 是同一批图像。文件存在时网页优先用它们（可被浏览器缓存、可直接右键另存），
  文件缺失时自动回退到内嵌版本——两条路径显示的像素完全相同。

## 首页排版（第 3 版）

首屏改为**左文右封面**：左侧标题、说明、三个入口与四项规格数字，右侧是整张封面 01。
在 1440×900 下整幅封面完整落在首屏内（550×388），点封面直接进阅读器并可放大到原始像素。

封面另备一张专用高清图 `pages/p01@2x.jpg`（2400×1696，由 PDF 原渲染 1684×1190 重采样 1.43×，799 KB）；
其余 23 页仍用 1400 px 常规图——封面是首屏唯一的大图，值得单独提清晰度。
窄屏（<980 px）自动改为上图下文单列。

## 章节卡片（第 4 版）

章节预览图原来用「原页取样框 + cover 放大」，在宽卡片上把 482px 宽的位置撑到 **2.4–3.9 倍像素**，
两侧还被裁掉，正文行被切在图框上下边缘——加了 `!important` 也没拦住。

现在改为**整页完整显示（contain）**：图片不裁切、不放大，1684:1190 的原始版式按卡片宽度等比缩放，
P22 成本表、P23 合规页这类密排正文都能完整读到（实测 990×701 容器内 `object-fit: contain`，0 报错）。
要看细节仍可点「查看整页」或点图进阅读器放大。

## 页面图像从哪来

全部由 `pypdfium2` 把 PDF **逐页真实渲染**得到：1684 × 1190 px → 网页用 1400 × 989 px（JPEG q86），
未作任何重绘、补完或裁切。A4 横版图版为 1.414 : 1，与 16:9 屏幕比例不同，阅读器选择「整页适配」以保留原始版式。

网页上的全部中文文案（章节名、页标题、页眉栏目、摘要）都取自同一批页面上的原文，
逐页目视核对后手工录入，见下表。

## 已知限制

1. **页面图像是位图**：整页渲染 1684×1190，放大到「原始像素」时 1:1 查看清晰；再往上放大必然发虚。
   需要超高倍细节时，应回到 `04_版式\assets\` 里的原生 SVG（`orthographic.svg`、`product_line.svg`、
   `guitue_seed*.svg`、`firing_curve.svg`）或对单页做 4× 重渲。
2. **检索是索引式**，覆盖 24 页的标题、页眉栏目与关键数据，不是 PDF 级别的全文逐字索引。
3. **没有做真实 PDF 在线预览**：网页展示的是 PDF 的渲染页，不是 PDF 文件本身。
4. 页面内嵌了 base64 图像，`index.html` 因此有 4.19 MB；若部署到公网，建议改走 `pages/` 外部文件
   （网页已优先使用外部文件，内嵌只是离线兜底）。
5. **深色模式不改变书页本身的颜色**：24 页是 PDF 直接渲染的浅色纸，那是作品原貌，夜间也不做反色或降亮处理；
   深色只作用于包住纸的那一层——背景、导航、卡片框、实验台、阅读器舞台、缩略条、灯箱。
   如果你希望「页面也跟着压暗」，可以再加一个对比度开关，但那会改变作品本身的观感，需要你确认。

## 深色模式（第 8 版）

| 项 | 做法 |
| --- | --- |
| 默认 | 没存过偏好时跟随系统 `prefers-color-scheme`；系统切换时会实时跟随 |
| 手动 | 顶栏按钮（图标 ☾/☀）或键盘 `T`；手动切过后写入 `localStorage.gq-theme`，此后以你的选择为准 |
| 层次 | 深色下不再用浅色投影，改成「压暗自发光 + 一圈 9% 的边界光 + 更深的纸影」把白纸从背景里分出来 |
| 主按钮 | 深底上深蓝按钮会糊成一团，改成浅蓝底 + 墨字（仅深色） |
| 选中态 | 色卡 / 关键词 / seed / 规格行不再铺满浅色块，改成浅蓝描边 + 提亮字 |
| 阅读器 | 舞台、顶栏、底栏、缩略条、进度条、前后预览带各自重算；缩略条用更深的底把空槽和页面拉开 |
| 灯箱 | 底色压到 `#0a0a09`，深色下按钮选中态换成浅蓝 |
| 控件色 | 地图（`--map-deep/--map-line/--map-route`）、成本条（`--cost-2`）、滑块 `accent-color` 全部收进 token，深色各有对应值 |
| 浏览器 | `meta[name=theme-color]` 随主题切换；`color-scheme: light dark` 让原生控件跟着走 |
